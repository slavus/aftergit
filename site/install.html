Install AfterGit

AfterGit installs into an existing Eclipse IDE from its update site. You need Eclipse IDE 2026-03 (4.39) or later running on Java 21 or later, with EGit and JGit 7.6 or later; the Eclipse IDE packages include EGit.

From the update site

The update site always offers every release, with the latest one selected by default:

https://slavus.github.io/aftergit/updates/
  1. In Eclipse choose Help → Install New Software…
  2. Press Add…, enter the name AfterGit and the location above, and press Add.
  3. Select the features you want under the category AfterGit (see the table below). Keep Contact all update sites during install to find required software ticked, so that Eclipse can fetch EGit or JGit from its own release repository if they are missing.
  4. Press Next, review the items, accept the Eclipse Public License 2.0 and press Finish.
  5. The AfterGit bundles are not signed, so Eclipse asks whether to trust them: select the unsigned AfterGit content, press Trust Selected, and restart Eclipse when asked.

Each release also has a site of its own, for example https://slavus.github.io/aftergit/updates/0.0.1/, if you want to stay on one version.

Which features to pick

Features on the AfterGit update site
FeatureWhat it bringsSelect it?
AfterGit Merge Resolver The three-pane resolver, auto-resolution, the .properties and MANIFEST.MF resolvers, Resolve All Simple Conflicts and the EGit integration. Yes, always.
AfterGit Merge Resolver: Java Support The result as a Java editor, the Java imports and members resolvers, the compile check. Needs the Java development tools (JDT). Comes with the main feature when JDT is installed.
AfterGit Merge Resolver: Languages TextMate syntax colours and the language server’s errors for other languages. Needs tm4e 0.17.2 and lsp4e 0.19.8 or later. Comes with the main feature when tm4e and lsp4e are installed.
AfterGit Merge Resolver: AI Agents (MCP) A local Model Context Protocol server (127.0.0.1 only, with a token) through which agents you run yourself read conflicts and propose resolutions. Optional. Off until you allow it in Preferences.
AfterGit Merge Resolver: Resolve with AI Asks a language model (the Anthropic Messages API or an OpenAI-compatible server such as OpenAI, Ollama or LM Studio) to resolve a conflict. Optional. Nothing is sent until you allow it and configure a model.

Java Support and Languages are optional parts of the main feature: Eclipse adds them on its own when their prerequisites are present, and leaves them out otherwise. If you install JDT, tm4e or lsp4e later, untick Group items by category in the install dialog and select the part on its own.

Both AI features are separate entries that the main feature does not include, and AfterGit works fully without them. Even when installed they do nothing until you switch them on under Preferences → AfterGit; every answer is shown as a purple ✨ block for you to review, and nothing saves or stages a file.

Offline, from the release zip

  1. Download aftergit-<version>-site.zip from the releases page. It holds the same p2 repository as the update site.
  2. In Eclipse choose Help → Install New Software… → Add… → Archive… and select the zip.
  3. Select the features as above, finish and restart.

Without a network connection Eclipse cannot fetch missing prerequisites, so EGit (and JDT, tm4e and lsp4e for the optional parts) must already be installed; untick Contact all update sites during install to find required software to keep Eclipse from trying.

From a local build

Build with mvn clean verify (JDK 21 or later, Maven 3.9 or later; see the README), then use Add… → Local… with the folder releng/net.aftergit.merge.site/target/repository.

Update

Choose Help → Check for Updates. Eclipse looks at the update site you added and offers the newest release. Read the changelog first: before 1.0 any release may change behaviour and preferences.

Uninstall

  1. Choose Help → About Eclipse IDE → Installation Details and open the Installed Software tab.
  2. Select the AfterGit features, press Uninstall…, finish and restart.

EGit’s own merge editor takes over again. Preferences you shared through a project’s .settings/net.aftergit.merge.ui.prefs stay in the project until you delete the file.
