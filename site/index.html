main (ours)

A git conflict resolver for EGit.

Result

◆A three-pane git conflict resolver for Eclipse and EGit.

feature (theirs)

A three-pane merge tool for Eclipse.

When a merge, rebase or cherry-pick stops with conflicts, double-click the file in Git Staging. AfterGit opens ours, the result and theirs side by side instead of EGit’s merge editor, resolves what it can resolve safely on its own, and keeps every automatic decision marked until you have looked at it.

To install it, add https://slavus.github.io/aftergit/updates/ under Help → Install New Software in Eclipse 2026-03 or later. The installation steps explain which features to pick, the quick start walks through a first merge, and the source is on GitHub.

How blocks are marked

Every change is a block with a full-line background in each pane where it has lines, and the changed words in a stronger shade. The colours below are the defaults of the light theme; the dark theme, a colour-blind safe and a high-contrast scheme have their own.

  • int precision = 3;

    Open conflict. Both sides changed these lines. Take a side, take both, ignore it or type the result yourself.

  • import java.util.Objects;

    Added by one side. Only ours or only theirs has these lines.

  • return values.stream()…

    Modified by one side. Only one side changed these lines.

  • int s = 0;

    Removed by one side. One side deleted these lines.

  • ◀int precision = 3;

    Resolved conflict. The side you took and the result are yellow; the result’s ruler shows ◀ for ours, ▶ for theirs or ◆ for both.

  • int precision = 4;

    Side not taken. Its text is not in the result: grey, struck through, outlined with dashes.

  • ✎int precision = 2;

    Typed by hand. You wrote the result yourself, so both sides turn grey and the ruler shows ✎.

  • Aif (b == 0) {

    Resolved by AfterGit, not reviewed. Teal and hatched with a filled “A” until you choose Mark Reviewed (✓).

  • Aif (b == 0) {

    Resolved by AfterGit, reviewed. Plain teal with an outlined “A”. Revert and Re-run still take it back.

  • int precision = 3;

    Proposed by AI. Purple and framed. Only with the optional AI features, and only after you allow them.

What it does

Resolving

Three panes
Ours | Result | Theirs, or Left + Result, Result + Right and Result Below, with connectors between the panes, an overview stripe and one shared scroll bar.
Taking sides
» and « in the connectors take a side, × ignores it. Take Both, Revert Block, and undo and redo that include the state of every block.
Every kind of conflict
Text conflicts open in the resolver. Binary and modify/delete conflicts offer Keep Ours, Keep Theirs or Delete File. Saving with open conflicts writes markers in the repository’s merge.conflictStyle.
Java
With JDT the result is a real Java editor with live errors, quick fix and content assist. Imports are fixed after a take, and an auto-resolved block that adds a compile error gets a red frame.
Structure column
Lists the members ours or theirs changed, who changed them and the state of their blocks, for Java, .properties and MANIFEST.MF. The Outline view shows the same.
Other languages
With tm4e and lsp4e: TextMate syntax colours in all three panes, and the errors of the file’s language server (Wild Web Developer, LemMinX and others) in the result.

Automatic resolution

When a file opens
Non-conflicting changes, word-level merges and an optional greedy pass are applied. Each automatic decision stays marked until you review it; Revert and Re-run take it back.
Structure-aware resolvers
Java imports and class members, .properties files per key, MANIFEST.MF per header and clause, and an optional “Newer version wins” for build descriptors such as pom.xml. Other plug-ins can add resolvers through an extension point.
Resolve All Simple Conflicts
For files, folders, projects or a whole repository, in the background. It ends with a summary, Stage Resolved Files and Undo Resolve All.

Eclipse integration

EGit
Optionally the Merge Tool of Git Staging; “Resolve in AfterGit…” in the explorers and the Team menu; Save & Mark Resolved saves, runs git add and closes; markers on files that still need attention.
Settings
Workspace and project settings, shareable through .settings. Key bindings for every command.
Themes
Colours for the light and dark themes, plus a colour-blind safe and a high-contrast scheme.

Optional AI

Resolve with AI
Asks a language model to resolve a conflict: the Anthropic Messages API or an OpenAI-compatible server such as OpenAI, Ollama or LM Studio.
AI agents (MCP)
A local Model Context Protocol server for agents you run yourself.
Off by default
Both are separate features. Nothing is sent until you allow it, and every answer is a proposal you review.

Requirements

  • Eclipse IDE 2026-03 (4.39) or later, running on Java 21 or later.
  • EGit and JGit 7.6 or later; the Eclipse IDE packages include them.
  • For the Java support: the Java development tools (JDT).
  • For other languages: tm4e 0.17.2 or later and lsp4e 0.19.8 or later.
  • Tested on Linux (GTK). The bundles are plain Java and SWT, but Windows and macOS are not tested yet.

0.0.1 is the first public release. I use it on real merges, but it is young: review the result before you commit. Known limitations are in the changelog; please report problems in the issue tracker.
